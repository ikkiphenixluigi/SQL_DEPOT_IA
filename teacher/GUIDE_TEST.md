# GUIDE_TEST.md

Guide pour tester tes requêtes SQL.

---

## Comment tester

1. Ouvre DB Browser ou DBeaver
2. Connecte-toi à la base `gestion_universitaire`
3. Ouvre un éditeur SQL
4. Écris ta requête
5. Exécute (F5)

---

## Vérifier tes résultats

- Compare avec les exemples dans les cours
- Vérifie le nombre de lignes
- Vérifie les valeurs

---

## Conseils

- Teste chaque requête plusieurs fois
- Vérifie les syntaxes
- Utilise les guides DB Browser et DBeaver
