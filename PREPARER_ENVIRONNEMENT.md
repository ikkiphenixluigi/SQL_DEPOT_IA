# Préparer son environnement

Avant de commencer les cours, prépare une copie du projet et choisis un outil pour travailler avec la base SQLite `gestion_universitaire`.

1. Récupère les fichiers du dépôt [SQL_DEPOT_IA](https://github.com/ikkiphenixluigi/SQL_DEPOT_IA).
2. Choisis l'un des deux guides ci-dessous selon l'outil que tu souhaites utiliser.
3. Initialise la base à l'aide des scripts fournis dans le dépôt ou suis la méthode décrite dans le guide de l'outil choisi.
4. Ouvre la base dans l'outil et commence à écrire tes premières requêtes SQL.

## Choisir un outil

- [DB Browser for SQLite]({{ '/preparer-environnement/db-browser/' | relative_url }}) : guide de prise en main de DB Browser et de la base du cours.
- [DBeaver Community]({{ '/preparer-environnement/dbeaver/' | relative_url }}) : guide de prise en main de DBeaver et de la base du cours.

Les deux guides sont des alternatives : un seul outil suffit pour suivre le cours.
